1. สินค้าและราคา

สินค้าคือไฟล์งานนำเสนอ PowerPoint (.pptx) ที่แก้ไขได้ ราคาและจำนวนชุดที่แสดงบนหน้าเว็บคือราคาและจำนวน ณ เวลาที่คุณสั่งซื้อ จ่ายครั้งเดียว ใช้ได้ตลอด ไม่มีค่าบริการรายเดือน

ชุดใหม่ที่เราเพิ่มเข้าคลังในภายหลัง ผู้ที่ซื้อแล้วดาวน์โหลดได้ด้วย Redeem Code เดิมโดยไม่มีค่าใช้จ่ายเพิ่ม

2. การสั่งซื้อและการชำระเงิน

ชำระเงินด้วยการโอนเข้าบัญชีบริษัท แล้วอัปโหลดสลิปในหน้าสั่งซื้อ ระบบตรวจสลิปอัตโนมัติ หากระบบอ่านสลิปไม่ได้ (เช่น สลิปจากระบบธนาคารของบริษัทที่ไม่มี QR) ทีมงานจะตรวจสอบยอดเงินเข้าบัญชีด้วยตนเองแล้วส่ง Code ให้

การส่งสลิปปลอมหรือสลิปที่ไม่ตรงกับยอดเงินที่เข้าบัญชีจริง เป็นเหตุให้เราปฏิเสธคำสั่งซื้อและระงับ Code ได้ทันที

3. การส่งมอบและ Redeem Code

เมื่อการชำระเงินผ่านการตรวจสอบ เราส่ง Redeem Code รูปแบบ TARN-XXXXXXXX ไปที่อีเมลที่คุณกรอกไว้ ใช้ Code นี้ปลดล็อกการดาวน์โหลดบนเว็บไซต์ Code ไม่มีวันหมดอายุ

Code 1 รหัส สำหรับผู้ใช้ 1 คน แพ็กทีมจะได้ Code แยกคนละรหัสตามจำนวนสิทธิ์ที่ซื้อ หากพบว่ารหัสถูกนำไปแจกจ่าย เราระงับรหัสนั้นได้โดยไม่คืนเงิน

เก็บอีเมลที่มี Code ไว้ หากทำหาย ติดต่อเราพร้อมหลักฐานการชำระเงิน เราจะออกรหัสใหม่ให้

4. สิทธิ์การใช้ไฟล์, ทำอะไรได้บ้าง

เมื่อชำระเงินแล้ว คุณได้รับสิทธิ์ใช้งานแบบไม่จำกัดจำนวนงาน ไม่จำกัดเวลา และโอนสิทธิ์ให้ผู้อื่นไม่ได้ ภายใต้ขอบเขตนี้

  • ใช้ทำงานนำเสนอของตัวเอง ของบริษัทที่คุณทำงานอยู่ หรือของลูกค้าที่คุณรับงานให้ ได้ไม่จำกัดจำนวนงาน
  • ใช้ได้ทั้งงานส่วนตัว งานในองค์กร การเรียนการสอน และงานเชิงพาณิชย์
  • แก้ไข เปลี่ยนสี เปลี่ยนข้อความ ตัดหน้าออก หยิบบางหน้าไปรวมกับไฟล์อื่นได้
  • นำเสนอต่อสาธารณะ ส่งออกเป็น PDF หรือวิดีโอ และเผยแพร่งานที่สร้างจากเทมเพลตได้
  • ไม่ต้องให้เครดิตเรา

5. สิ่งที่ทำไม่ได้

ลิขสิทธิ์ในไฟล์เทมเพลต เลย์เอาต์ และภาพตัวอย่างบนเว็บไซต์ ยังเป็นของบริษัท ดับเบิ้ลคราฟ์ จำกัด สิ่งที่คุณได้คือสิทธิ์ใช้งาน ไม่ใช่การโอนลิขสิทธิ์

  • ห้ามขายต่อ แจกจ่าย ให้ยืม หรืออัปโหลดไฟล์เทมเพลต ไม่ว่าจะมีค่าตอบแทนหรือไม่
  • ห้ามแชร์ Redeem Code หรือบัญชีที่ปลดล็อกแล้วให้ผู้อื่น
  • ห้ามนำเทมเพลตไปขายต่อเป็นเทมเพลต หรือรวมอยู่ในชุดสินค้า คอร์ส หรือบริการที่ขายต่อ ไม่ว่าจะแก้ไขมากน้อยเพียงใด
  • ห้ามอ้างว่าเป็นผู้ออกแบบเทมเพลตนี้ และห้ามจดทะเบียนเครื่องหมายการค้าหรืออ้างลิขสิทธิ์ในตัวเทมเพลตหรือเลย์เอาต์
  • ห้ามนำภาพตัวอย่างบนเว็บไซต์ไปใช้โฆษณาสินค้าของตนเอง

เส้นแบ่งที่เข้าใจง่าย งานนำเสนอที่คุณสร้างจากเทมเพลต คุณขายและเผยแพร่ได้เต็มที่ แต่ ตัวเทมเพลตเปล่า จะขายต่อหรือแจกต่อไม่ได้

6. ห้ามดูดข้อมูลและทำซ้ำด้วยระบบอัตโนมัติ

ภาพสไลด์ตัวอย่างบนเว็บไซต์นี้เป็นงานอันมีลิขสิทธิ์ เผยแพร่เพื่อให้ผู้สนใจดูตัวอย่างก่อนตัดสินใจซื้อเท่านั้น

  • ห้ามใช้โปรแกรม สคริปต์ บอต หรือระบบอัตโนมัติใด ๆ ดึง คัดลอก หรือจัดเก็บภาพและข้อมูลจากเว็บไซต์เป็นจำนวนมาก
  • ห้ามนำภาพจากเว็บไซต์นี้ไปใช้ฝึกสอน ปรับจูน หรือป้อนเข้าระบบปัญญาประดิษฐ์ เพื่อสร้างงานออกแบบที่ลอกเลียนหรือทดแทนเทมเพลตของเรา
  • ห้ามทำซ้ำหรือดัดแปลงเลย์เอาต์และการจัดวางของเทมเพลตขึ้นใหม่เพื่อนำไปขายหรือแจกจ่าย ไม่ว่าจะทำด้วยมือหรือด้วยเครื่องมืออัตโนมัติ
  • ห้ามดึงรูปจากเว็บไซต์นี้ไปแสดงบนเว็บอื่น (hotlink)

เราสงวนสิทธิ์ในการจำกัดหรือระงับการเข้าถึงเว็บไซต์จากที่อยู่ที่มีพฤติกรรมดังกล่าว รวมถึงดำเนินการตามกฎหมายลิขสิทธิ์

7. ใบกำกับภาษี

ขอใบกำกับภาษีได้ตั้งแต่ตอนสั่งซื้อ โดยติ๊กในหน้าชำระเงินและกรอกข้อมูล ออกได้ทั้งในนามนิติบุคคลและบุคคลธรรมดา คุณได้รับ Redeem Code ทันทีโดยไม่ต้องรอเอกสาร ส่วนใบกำกับภาษีจัดส่งทางไปรษณีย์ภายใน 7 ถึง 10 วันทำการ ข้อมูลที่กรอกผิดและทำให้ต้องออกเอกสารใหม่ อาจมีค่าใช้จ่ายในการจัดส่งเพิ่ม

8. การคืนเงิน

สินค้าเป็นไฟล์ดิจิทัลที่ส่งมอบทันทีและทำซ้ำได้ เมื่อได้รับ Redeem Code แล้วจึงไม่สามารถยกเลิกหรือขอคืนเงินได้ กรุณาดูตัวอย่างสไลด์บนเว็บไซต์ให้พอใจก่อนตัดสินใจ ตัวอย่างเปิดดูได้ทุกชุดโดยไม่ต้องซื้อ

หากไฟล์เสียหาย เปิดไม่ได้ หรือได้รับไม่ครบ แจ้งเราภายใน 7 วันนับจากวันที่ได้รับ Code เราจะแก้ไขหรือส่งไฟล์ให้ใหม่

9. ความรับผิด

เราดูแลให้ไฟล์เปิดใช้งานได้ตามที่อธิบายไว้ แต่ไม่รับประกันว่าเทมเพลตจะเหมาะกับวัตถุประสงค์เฉพาะของคุณ และไม่รับผิดต่อความเสียหายที่เกิดจากการนำไปใช้ เช่น ผลของการนำเสนอหรือการตัดสินใจทางธุรกิจ ความรับผิดสูงสุดของเราไม่เกินจำนวนเงินที่คุณชำระจริง

เว็บไซต์และไฟล์ให้บริการผ่านผู้ให้บริการภายนอก (Cloudflare, Supabase, Google Drive) อาจมีช่วงที่เข้าใช้ไม่ได้ชั่วคราว

10. การเปลี่ยนแปลงเงื่อนไขและกฎหมายที่ใช้บังคับ

เราอาจแก้ไขเงื่อนไขนี้ โดยจะอัปเดตวันที่ด้านบน การแก้ไขไม่กระทบสิทธิ์การใช้ไฟล์ที่คุณซื้อไปแล้ว

เงื่อนไขนี้อยู่ภายใต้กฎหมายไทย และให้ศาลไทยเป็นศาลที่มีเขตอำนาจ
